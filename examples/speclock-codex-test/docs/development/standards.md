# 工程与编码规范

本仓库为认证模块核心服务，所有代码与文档修改在实施、验证及评审阶段均须严格遵守以下基线规范。

## 1. 安全比对
- 所有令牌、密钥及敏感凭证的比对操作，必须使用标准库 `hmac.compare_digest`。
- 禁止使用 `==` 直接比较令牌字符串，防止时序攻击。
- 对非法输入（如空串、空白字符串、错误类型或非正数参数）应明确拒绝或抛出约定异常。

## 2. 时间可测性
- 涉及令牌签发时间、有效期计算与过期判断的公开方法，必须支持可选参数 `now: Optional[float] = None`。
- 当 `now` 为 `None` 时默认读取 `time.time()`；存在有效期限时按显式时间阈值判定过期。
- 单元测试必须通过传入确定性时间戳覆盖过期临界与未过期边界，禁止依赖真实 `time.sleep`。

## 3. 中文注释与文档字符串
- 所有公开类、方法及函数必须具备清晰的简体中文 docstring，简明说明核心职责、关键参数与边界行为。
- 涉及安全校验或状态流转的非显而易见逻辑，应补充简洁的简体中文注释说明设计原因。

## 4. 必过验证与门禁纪律
- 仅使用 Python 标准库实现业务逻辑与测试，不引入第三方依赖。
- 任何代码或文档变更完成后，必须完整跑通以下两条验证命令：
  - 单元测试：`python3 -m unittest discover -s src`
  - 文档与配置检查：`python3 scripts/check_docs.py --check-config`
- 禁止通过删减断言、跳过测试用例或屏蔽检查项来伪造验证通过。
- 任务卡最终评审通过时仅回写协作状态，不得越权代勾人工验收完成框。
