# 认证模块任务卡

> 本文件按 `workflow-core` 7 字段精简任务卡约定维护；业务与编码约束见 [工程与编码规范](../../development/standards.md)。

### AUTH-R01 基础登录令牌非空校验

- [x] 子需求完成（人工验收通过）
- 来源：认证服务首期基线
- 状态：已验收
- 验收：空串与纯空白令牌返回 False，非空令牌返回 True。

### AUTH-R02 令牌签发与恒定时间校验

- [x] 子需求完成（人工验收通过）
- 来源：认证服务安全加固
- 状态：已验收
- 验收：支持通过 TokenStore 签发令牌并使用 hmac.compare_digest 校验，错误或未知令牌返回 False。

### AUTH-R03 API Token 过期与吊销校验

- [ ] 子需求完成（仅人工验收通过后勾选）
- 来源：认证服务安全治理需求
- 状态：待处理
- 验收：1）TokenStore.issue_token 支持可选 ttl_seconds 参数（传入时必须 > 0，否则抛 ValueError）；2）令牌超过过期时间后 verify_token 返回 False，verify_token 支持传入可选 now 参数便于确定性测试；3）新增 revoke_token(token) 吊销指定令牌，吊销后即使未过期 verify_token 也返回 False，对不存在或已吊销令牌重复调用保持幂等；4）全程使用 hmac.compare_digest 比对并补充正常/过期/吊销/非法 TTL 边界单测。
