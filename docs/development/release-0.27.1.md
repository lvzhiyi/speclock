# SpecLock (workflow-core 0.27.1) — 看板以 Git 任务卡为主清单并仅叠加本机活跃开发态

- **通用任务卡解析与状态映射**：放宽 `dashboard_data.py` 任务卡标题正则，支持 `BASE-UI07`、`AUTH-01`、`MOD-R1` 等研发任务编号并避免误匹配日期小节；将「评审通过 / 评审通过，待人工验收 / 待人工验收」映射为 `review_passed`，「已验收」映射为 `completed`，解析时自动剥离行内注释与分号附带字段。
- **理顺 Git 任务卡与本机 `.speclock` 的合并优先级**：本机 `cancelled` 记录存在同名 Git 任务卡时保留 Git 任务卡状态不被覆盖，无同名 Git 任务卡的已取消临时任务不再进入看板总表；本机未开工旧草稿（`created` 且无尝试记录与已完成步骤）不覆盖已过审或结案的 Git 任务卡；本机处于活跃执行态时正常叠加实时护栏进度。
- **看板展示与误报修复**：状态筛选下拉框移除「已取消」，纯 Git 任务卡直接展示来源与状态提示（不再显示无意义的「档位未知 · 阶段未知」和空护栏条）；修复无评审记录时因存在 `control_digest` 误报 `invalidated`（「双轴评审：未通过 ×」）及 `cancelled` 任务仍显示阻止条件的问题。
